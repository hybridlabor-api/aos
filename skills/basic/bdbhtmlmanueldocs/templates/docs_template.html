Getting Started mit BDB OS Remote

Getting Started with BDB OS Remote

Von unterwegs arbeiten, als säßest du direkt zuhause vor deinem leistungsstarken Arbeits-Computer.

Work from anywhere as if you were sitting right at your powerful home workstation.

Einführung & Funktionsweise

Overview & Architecture

Stell dir vor, du hast zuhause einen sehr leistungsstarken Computer stehen, auf dem all deine Projekte, Dateien und dein digitaler Assistent ("Claude Desktop") liegen. Wenn du unterwegs bist – zum Beispiel im Zug oder im Café – möchtest du trotzdem so arbeiten können, als würdest du direkt vor diesem Computer sitzen.

Imagine you have a powerful workstation at home hosting your heavy projects, databases, and Claude Desktop with its MCP toolchain. When traveling, BDB OS Remote allows you to access this entire environment from your laptop seamlessly over an encrypted WireGuard mesh.

Voraussetzungen

Prerequisites

Pre-Flight Checkliste Pre-Flight Checklist 0/5

Schritt 1: Arbeits-Computer einrichten

Step 1: Set Up Workstation

Führe diesen Schritt auf dem Computer aus, der zuhause / im Studio stehen bleibt:

Perform this step on the workstation that remains at home / in the office:

  1. Öffne das Terminal und starte den interaktiven Setup-Assistenten: Open the terminal and run the interactive setup installer:
    bash
    $npx @hybridlabor-api/bdb-os-remote@latest installer
  2. Wähle im Menü die Option [1] Workstation aus. Select option [1] Workstation in the interactive menu.
  3. Der Dienst lauscht nun im Hintergrund auf Port 8000 über dein Tailscale-Netzwerk. The gateway service is now running and listening on port 8000 via your Tailscale mesh.

Schritt 2: Laptop verbinden

Step 2: Connect Laptop

Führe diese Schritte auf deinem mobilen Laptop aus:

Execute these steps on your mobile laptop:

  1. Starte den Installer auf dem Laptop: Run the installer on your laptop:
    bash
    $npx @hybridlabor-api/bdb-os-remote@latest installer
  2. Wähle Option [2] Laptop und gib den Tailscale-Namen deines Arbeits-PCs ein. Select option [2] Laptop and enter your Workstation's Tailscale host name.
  3. Starte Claude Desktop komplett neu (Cmd+Q & neu öffnen). Restart Claude Desktop completely (Cmd+Q & relaunch).

Offline-Modus (BDB Pull)

Offline Mode (BDB Pull)

Für Situationen ganz ohne Empfang (Flugzeug, Funklöcher) lädst du ein Projekt vorab herunter:

For zero-connectivity situations (flights, tunnels), pull a local snapshot of your project:

bash
$npx @hybridlabor-api/bdb-os-remote pull mein-projekt

Das Projekt wird ohne schwere Ordner (wie node_modules) blitzschnell nach ~/bdb-dev-local/ geklont.

The project is cloned to ~/bdb-dev-local/ with heavy caches automatically excluded.

Software aktuell halten

Software Updates

Führe einfach denselben Installer-Befehl erneut aus und wähle „Update“:

Simply rerun the installer command and choose “Update”:

bash
$npx @hybridlabor-api/bdb-os-remote@latest installer
