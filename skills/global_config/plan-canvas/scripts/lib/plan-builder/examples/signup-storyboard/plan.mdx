# Signup flow

## Goal

A new visitor reaches an empty, ready-to-use dashboard in six screens or fewer. All names and data in this example are invented.

## Decision

<Decision title="Verification method" question="How do we verify the email address?" options={[
  { id: "code", label: "Six digit code", detail: "Works when the mail app opens on another device.", recommended: true },
  { id: "link", label: "Magic link", detail: "One tap, but breaks when the link opens in a different browser." },
]}>

A code survives a device switch, which is the common failure for links.

</Decision>
