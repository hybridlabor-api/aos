# Harbor Notes: Team Notes MVP

## Goal

Harbor Notes is a team notes app. A small team signs up, creates a workspace, writes notes together and shares a read-only link with someone outside the team. The first private beta ships in six weeks. All names and data in this plan are invented.

- A new user reaches a working workspace in under two minutes.
- Two teammates edit the same note without losing text.
- A shared link works without an account and can be revoked at any time.

## Decision

<Decision title="How do users verify their email?" question="Which proof do we ask for after the signup form?" options={[
  { id: "code", label: "Six digit code", detail: "Survives a device switch, which is the common failure for links.", recommended: true },
  { id: "link", label: "Magic link", detail: "One tap, but breaks when the link opens in a different browser." },
  { id: "none", label: "No verification in the beta", detail: "Fastest, but invites cannot be trusted and bounces go unnoticed." },
]}>

A code works on the phone and the laptop alike, and costs one extra input box. We can add magic links later without changing the data model.

</Decision>

## Architecture

<Callout tone="note" title="Why a queue and a worker">

Exports and invitation emails can take seconds. Running them off the request path keeps the editor responsive and lets us retry a failed job without the user waiting.

</Callout>
