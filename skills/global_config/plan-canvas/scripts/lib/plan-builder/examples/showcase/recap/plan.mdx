## Summary

Until now a note could only be read by workspace members. This change adds read-only share links for people outside the team. A link carries a random token, expires after seven days unless the owner picks another period, and can be revoked at any time. Recipients see a clean read-only page; expired or revoked links show a Gone page instead of an error.

- Tokens are 128 bit random values stored hashed; the plain token only appears in the URL.
- The public page never loads the editor bundle, so it opens fast on slow connections.
- Owners see who opened a link and how often, without personal data.

## Decision

<Decision title="Token storage" question="How do we store share tokens?" options={[
  { id: "hash", label: "Store only a hash", detail: "A database leak does not expose working links.", recommended: true },
  { id: "plain", label: "Store the token", detail: "Lets us show the link again, but a leak exposes every link." },
]}>

The dialog shows the full link once. After that only the owner can revoke it and create a new one, which is an acceptable cost for the safer default.

</Decision>
