<Annotation id="note-code" title="Code entry" targetId="verify" placement="right">

Paste fills all six boxes at once. The code expires after ten minutes and a resend invalidates the old one.

</Annotation>

<Annotation id="note-lock" title="Title lock" targetId="editor" placement="bottom">

While one person edits the title, others see it locked. Body text merges by last write per note.

</Annotation>

<Annotation id="note-expiry" title="Safe default" targetId="share" placement="bottom">

New links expire in seven days. Revoking takes effect within one minute.

</Annotation>

<Annotation id="note-danger" title="Destructive actions" targetId="settings" placement="bottom">

Delete needs the workspace name typed again and is only visible to owners.

</Annotation>
