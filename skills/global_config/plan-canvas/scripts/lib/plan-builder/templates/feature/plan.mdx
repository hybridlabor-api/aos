## Goal

Trailmark is a fictional hiking app. Saved Routes lets a hiker bookmark a route from the map, find it again offline and sync it across devices. The feature ships to the beta group in four weeks.

- A hiker saves a route in two taps from the map.
- Saved routes open without a network connection.
- A route saved on the phone shows up on the tablet within a minute.

## Storyboard

Four screens in canvas.mdx cover the happy path: map, save sheet, saved list, route detail.

## Decision

<Decision title="Where do saved routes live?" question="Which store is the source of truth for a saved route?" options={[
  { id: "local-first", label: "Local database with background sync", detail: "Works offline by design, needs a conflict rule.", recommended: true },
  { id: "server", label: "Server only, cached reads", detail: "Simple model, but the list is empty offline until cached." },
  { id: "file", label: "Exported GPX files", detail: "Portable, but no sync and no list ordering." },
]}>

Hikers lose signal on exactly the trails they want to follow. A local database makes offline the normal case, and last-edit-wins per route is enough for one person using two devices.

</Decision>
