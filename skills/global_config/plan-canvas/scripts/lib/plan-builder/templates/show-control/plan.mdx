# Tidewater Night: Technical Plan for the Live Show

<Callout tone="note" title="How to use this template">

Replace the show, venue, fixture counts, universes and cues with your own. Keep the signal flow, the patch table, the cue list and the failure plan: crew reads these first. The board in the Canvas section is a rough plan view; redraw it for your stage. All names and numbers below are invented.

</Callout>

## Goal

Run a 75 minute festival headline set with synchronised lighting, LED wall video and a two-person audio team, driven by one timecode source and with a defined fallback for every critical link.

- Show opens on timecode 01:00:00:00 and every cue is repeatable from any song start.
- A single failure in network, media or console never causes a full blackout.
- Load-in is done by 14:00, line check by 16:00, doors at 19:00.

## Decision

LTC from the audio playback laptop is distributed to the console and the media server. Both fall back to their internal clocks if LTC drops, which is on the failure plan.

</Decision>

## Failure and blackout plan

<Table title="Failure modes and responses" columns={["Failure", "Detected by", "Immediate response", "Recovery"]} rows={[
  ["LTC lost", "Console timecode lamp, media server clock", "Both switch to internal clock, operators GO manually", "Re-sync at the next song start"],
  ["Media server A fails", "Wall black or frozen", "Video operator flips to server B on the processor", "Reboot A, keep B live for the set"],
  ["DMX node 1 fails", "Truss fixtures freeze", "Console outputs to spare node on universe 4 port", "Replace node during the next break"],
  ["Network switch fails", "All sACN lost, fixtures hold last look", "Swap to the spare switch, config is on USB", "Verify addresses, resume"],
  ["Power loss on stage", "Lights and wall dark", "Audio on UPS keeps playback, house lights on emergency circuit", "Hold the show until power is confirmed"],
  ["Emergency stop", "Production manager call", "Console blackout, haze and CO2 off, house lights up", "No restart without a safety sign-off"],
]} />

<Callout tone="warning" title="Blackout rule">

A deliberate blackout is a console cue (cue 1 and cue 60) and never a power switch. If any department calls "stop", all effects (strobe, CO2, haze) go off first, then lights fade to house. Only the production manager restarts the show.

</Callout>
