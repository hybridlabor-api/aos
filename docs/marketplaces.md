# AOS through the native plugin marketplaces

Every manifest referenced here is in this repository; versions are stamped to
`package.json` by `npm run plugin:build` and checked by `tests/marketplace-manifests.test.mjs`.

| Harness | Manifest | Install | Lands at | Update |
|---|---|---|---|---|
| Claude Code | [`.claude-plugin/marketplace.json`](../.claude-plugin/marketplace.json) (entries `bdb-aos`, `bdb-aos-fleet`) + generated [`plugin.json`](../.claude-plugin/plugin.json) | `claude plugin marketplace add hybridlabor-api/aos` then `claude plugin install bdb-aos@bdb-marketplace` | `~/.claude/plugins/cache/bdb-marketplace/bdb-aos/<version>/` | `claude plugin marketplace update bdb-marketplace` then `claude plugin update bdb-aos@bdb-marketplace` |
| Codex CLI | [`.agents/plugins/marketplace.json`](../.agents/plugins/marketplace.json) + [`plugins/bdb-aos-codex/`](../plugins/bdb-aos-codex/.codex-plugin/plugin.json) | `codex plugin marketplace add hybridlabor-api/aos` then `codex plugin add bdb-aos@bdb-aos` | `~/.codex/plugins/cache/bdb-aos/bdb-aos/<version>/` | re-run `codex plugin add bdb-aos@bdb-aos` after `codex plugin marketplace upgrade bdb-aos` (Codex has no `plugin upgrade`) |
| Antigravity (agy) | root [`plugin.json`](../plugin.json) at the plugin root | `agy plugin install <local plugin directory>` (the CLI takes a local directory only; GitHub `owner/repo` is not an accepted target) — normally run by the AOS installer (`npx -y @hybridlabor-api/aos@latest`) or `node <aos-pkg>/lib/agy-plugin-install.js` | `~/.gemini/config/plugins/bdb-aos/` | re-run the installer (it re-stages and re-installs when the version differs), then `agy plugin enable bdb-aos` if needed |
| OpenCode | [`.opencode/plugins/bdb-aos.js`](../.opencode/plugins/bdb-aos.js) | copy the plugin file into `.opencode/plugins/` (project) or `~/.config/opencode/plugins/` (global), or list an npm package under `plugin` in `opencode.json` | loaded at startup from the plugin directory | overwrite the file with the new version's copy |

Notes on what was verified and what was not:

- **Claude Code** (`https://code.claude.com/docs/en/plugin-marketplaces`): a marketplace is a `.claude-plugin/marketplace.json` with `name`, `owner` and a `plugins` array; relative `source` paths are written from the marketplace root and must not contain `..`; install id is `<plugin-name>@<marketplace-name>`; the entry name and the plugin's manifest name must match. The exact update-command semantics (`plugin update`, `marketplace update`) come from this repo's own measured `lib/plugin-migration.js` notes, not the docs page.
- **Codex** (`https://developers.openai.com/codex/plugins/build` and `https://developers.openai.com/plugins/build/plugins.md`): the manifest is `.codex-plugin/plugin.json` at the plugin root; a repo marketplace lives at `$REPO_ROOT/.agents/plugins/marketplace.json` with `name`, `interface.displayName`, and `plugins[]` carrying `source: {source: "local", path: "./..."}` relative to the marketplace root, `policy.installation`, `policy.authentication` and a `category`; CLI commands `codex plugin marketplace add owner/repo|local-dir` and `codex plugin add <plugin>@<marketplace>`; the cache path is `~/.codex/plugins/cache/$MARKETPLACE_NAME/$PLUGIN_NAME/$VERSION/`.
- **Antigravity / agy** (`https://antigravity.google/docs/plugins`, `https://www.agy.dev/docs/cli/plugins`): a plugin is a directory with a required `plugin.json` at its root (`name` matching `^[a-zA-Z0-9-_]+$`, optional `$schema` pointing at `https://antigravity.google/schemas/v1/plugin.json`); manual install is a directory placed in `~/.gemini/config/plugins/` (global) or `.agents/plugins/` (workspace); the CLI exposes `agy plugin list | install <dir> | enable | disable | uninstall`. Antigravity offers its own marketplace only through Google's surface — no public self-hosted marketplace manifest format exists, so AOS ships no agy marketplace file.
- **OpenCode** (`https://opencode.ai/docs/plugins/`): plugins are local JS/TS files in `.opencode/plugins/` or `~/.config/opencode/plugins/`, or npm packages in the `plugin` array of `opencode.json`. There is **no marketplace concept**; no marketplace file is shipped.
- **skills.sh** discovery (`npx skills add hybridlabor-api/aos`) is out of scope for this page.

The npm installer (`npx -y @hybridlabor-api/aos@latest`) remains the supported all-in-one route: it detects harnesses, wires hooks and MCP config, and performs these plugin registrations itself (`lib/plugin-migration.js`, `lib/codex-plugin-install.js`, `lib/agy-plugin-install.js`), best-effort on every harness.
