Installation Manual

Deploy the BDB Creative OS to any AI Agent environment (Antigravity, Claude, Cursor, Windsurf, Roo Code, Cline, Aider, or custom frameworks). The smart installer auto-scans your system or allows fully manual custom path specification.

One-Command Setup

Run the interactive installer via NPM. It will auto-scan your system for active configurations and prompt you for custom targets or merge modes.

# Works on macOS, Windows, Linux
npx @hybridlabor-api/bdb-antigravity-skills

Supported & Auto-Detected Environments

  • Google Antigravity: Target: ~/.gemini/config/.
  • Claude Desktop & Code: Automatically wires into claude_desktop_config.json.
  • Cursor, Windsurf, Roo Code, Cline: Configures workspace folders or global mcp JSON configurations.
  • Custom Path Mode: Provide target paths manually for any developer agents (e.g. ChatGPT Codex, Aider, custom python frameworks).
